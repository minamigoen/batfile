# batfile

Windows 環境で使えるバッチファイル置き場です。  
Google ドライブ（デスクトップ版）を利用した **robocopy 差分コピー** 用のサンプルを公開しています。

---

## ディレクトリ構成

```
batfile/
 ├─ 差分コピー/
 │   ├─ 差分コピー.bat   # 実行用バッチファイル（UTF-8対応）
 │   └─ paths.txt        # コピー元とコピー先を指定する設定ファイル
 └─ README.md            # この説明ファイル
```

---

## 差分コピーについて

Google の個人アカウントから Google Workspace へ移行する際、  
マイドライブから共有ドライブへのコピーに活用できます。

- **更新分だけ差分コピー**できるので効率的  
- 大量のファイルを少しずつ移行するのに最適  
- Google ドキュメント形式（Docs/Sheets/Slides）は対象外 → 別途移行が必要

---

## 使い方

1. `paths.txt` にコピー元・コピー先を記載します
   ```txt
   H:\マイドライブ\コピー元
   H:\共有ドライブ\40_共有\コピー先
   ```
2. `差分コピー.bat` をダブルクリック  
3. robocopy による差分コピーが開始されます

> 文字化け対策として `差分コピー.bat` の先頭で `chcp 65001` を実行しています。
